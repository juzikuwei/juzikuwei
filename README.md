I am **juzi**, and I build AI-native applications that are **testable, observable, and grounded in evidence**.

I am currently building **[AI/Agent Tech Radar](https://github.com/juzikuwei/tech-radar-agent)** — a local research assistant for AI-agent papers. It combines hybrid retrieval (multilingual E5, BM25, RRF, cross-encoder reranking), a bounded tool-calling ReAct agent, deterministic citation validation, token-triggered conversation compaction, and a read-only MCP server.

Before that, I built **[Focus Lab](https://github.com/juzikuwei/focus-group-AI-Agent)** — an AI-assisted virtual focus group prototype with multi-model interviews, streaming reports, and structured-output recovery.

Those projects shaped how I build: scope before framework, evidence before confidence, and failure paths treated as product behavior.

My main interests are **retrieval-grounded generation**, **bounded agent systems**, and **LLM evaluation**. I enjoy turning AI product ideas into workflows that are simple to run, easy to test, and reliable when things go wrong — not just impressive in a demo.
