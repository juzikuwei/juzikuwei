## About

I build AI-native products that are **testable, observable, and grounded in evidence**.

My current work connects retrieval systems, tool-calling agents, structured outputs, and evaluation into workflows that can survive failure instead of only looking good in a demo.

> 中文简介：把 AI 产品想法做成可测试、可观测、可验证的工作流。

## What I'm building

| Focus | What it means in practice |
| --- | --- |
| **RAG & retrieval** | Hybrid search, reranking, multilingual evidence, and retrieval evaluation |
| **Agent systems** | Bounded ReAct loops, tool boundaries, fallback paths, and citation checks |
| **AI product prototyping** | Fast experiments with streaming UX and structured model outputs |
| **Engineering discipline** | Small milestones, explicit trade-offs, offline tests, and useful traces |
